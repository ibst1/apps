Small Windows apps

Free tools I've built for my own work and share with anyone who finds them useful. Most are portable: download, unzip and run. No installation and no admin rights needed.

"Windows protected your PC"? The apps aren't code-signed yet, so Windows SmartScreen may warn the first time. Click More info → Run anyway. All source code is public on GitHub if you want to check what a program does.
